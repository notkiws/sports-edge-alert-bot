# Free-Data Sports Probability Alert Bot V1 Implementation Plan

> **For Hermes:** Execute task-by-task with strict RED–GREEN–REFACTOR TDD. `STRATEGY.md` is authoritative.

**Goal:** Build a private Telegram bot using football-data.org for calibrated football probability forecasts and Tennis-Data plus Polymarket for independent tennis edge detection.

**Architecture:** Immutable provider snapshots feed point-in-time feature pipelines. Football score models return up to three individually ≥60% options per qualifying match without using odds. A surface-aware tennis model is matched strictly to individual Polymarket contracts and compared with executable CLOB ask VWAP.

**Tech Stack:** Python 3.11+, Pydantic, HTTPX, Polars, DuckDB/Parquet, SQLite, scipy/statsmodels/scikit-learn, APScheduler, python-telegram-bot, pytest/Hypothesis, Ruff, mypy.

## Acceptance criteria

- [ ] Free football account coverage is measured and unsupported competitions disabled.
- [ ] Every displayed football option is individually ≥60%; maximum three per match.
- [ ] Football messages contain no odds, edge, EV, or value-bet claim.
- [ ] Tennis model is independent of Polymarket price input used for evaluation.
- [ ] Tennis contracts are exact individual match-winner matches.
- [ ] CLOB ask/VWAP, not midpoint, is used.
- [ ] Tennis probability, top-50, price-ceiling, edge, sample, and freshness rules pass.
- [ ] No accumulator, stake, bookmaker credential, trading, or ATP/WTA scraping code exists.
- [ ] One bilingual UTC+7 daily report is idempotent.
- [ ] Full tests, lint, type checks, backtests, and dry run pass with real outputs.
